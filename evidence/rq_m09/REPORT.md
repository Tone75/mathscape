# RQ-M09｜標本を変えても、同じ結論？

2026-11-10。受入済みM08と同じ生成分布から新しい60原標本を事前登録後に生成し、共有120系列予算のP30（4×30）とP120（1×120）を追試した。**新コホート単独の固定判定では、平均Ase移動±.0025と平均反復分散比(.8,1.25)の同等性が、Gamma（G）・lognormal（L）の両方で支持された。H1／H2の全体判定も支持である。** 主実験1回、再実行0、60原標本・144,000内側系列を完了し、無効・欠測0。別実装の保存監査は不一致0だった。

この結論はn20・α=.05・B4999・予算反復R20・各分布N30・有限KのP30対P120に限る。差が厳密0、全原標本で同等、全分布・全標本数での再現、普遍的な最適配分、絶対偏り・RMSE・被覆改善を示したものではない。P120は有限の比較対象で真値ではない。M08の受入結果は保持し、新旧のpool、旧新IDでの対応比較、新しいコホート間検定・比較区間は作成していない。

## 問い・事前固定・原標本生成の順序

### 母分布と解析的標準化

両母分布の理論平均0・分散1・歪度2を維持し、各原標本を平均0／分散1へ再標準化していない。

G：`y ~ Gamma(shape=1, scale=1)`、`x=y-1`。L：`z ~ N(0,1)`、`v=2*sinh(asinh(1)/3)`、`t=1+v²`、`s=sqrt(log1p(v²))`、`m=sqrt(t)`、`d=m*v`、`x=(exp(s*z)-m)/d`。受入済み[matched_moments.py](../../mathscape/matched_moments.py)のPython math定数とNumPy vector演算順序を保持し、丸めた定数を計算入力にしていない。表示用の値は次のとおり。
| 分布 | 解析定数（保存値） |
| --- | --- |
| gamma | shape=1.0, scale=1.0 |
| lognormal | v=0.5960716379833215, t=1.3553013976081199, s=0.5513835899408821, m=1.1641741268419084, d=0.6939311786844594 |

Lのvは`v³+3v=2`を満たし、lognormalの解析的歪度は`v(v²+3)=2`となる。平均・分散・歪度を合わせても分布全体は同じではなく、支持域・高次モーメント・尾部などが違う。この比較から尖度だけの因果効果を分離しない。推論関数には真値・母分布ラベルを入力せず、真値0は保存結果のC／miss評価にだけ使う。

## 測定量と固定判定

各組で端点のddof1標本分散から、`V=(var(lower)+var(upper))/(2*SE²)`、`A=sqrt(V)`を求める。各配分の予算推定値は`T=mean_j(sqrt(V_j))`、各原標本について`M=mean_r(T)`、`Q=var_r(T,ddof=1)`である。**平方根の後に平均する**。`sqrt(mean_j(V_j))`や先頭1組のM07量に置き換えない。

保存表の`Ase=T`、`Vse=Vbar=mean_j(V_j)`であり、J>1では一般に`Vse != T²`。lower_sd／upper_sd／S／Apopも組ごとの量を平均した配分指標で、120端点を常に一括したSDではない。`S=sqrt((var(lower)+var(upper))/2)`、`Ase=S/SE`、`Apop=S/(1/sqrt(20))`を組ごとに計算する。`Q/R`はMの条件付き分散の記述推定で、主対象Qと区別する。

`C=mean(下端≤0≤上端)`、`Mbelow=mean(上端<0)`、`Mabove=mean(下端>0)`、`miss_T=Mbelow-Mabove`を別に保持する。`miss_T`は区間の外れ方向で、予算推定値Tとは別の量である。95%区間のC／幅を99.5%の配分比較区間と混同しない。

原標本ごとの主量は`d=mean_r(T120−T30)`、`L=Q120−.8*Q30`、`U=Q120−1.25*Q30`。各分布N30、df29、平均±`t(.9975,29)*SD/sqrt(30)`の両側99.5%近似t区間を各3本、計6本使う。seed別N10・df9は記述のみで、方向ゲートはない。P60、percentile、t、被覆、分解は追加の確認仮説にしない。

- H1：d区間が厳密に`(-.0025,.0025)`内なら支持。下端>.0025または上端<−.0025なら不支持。境界接触・交差は保留。単位はAseで、percentage pointではない。
- H2：正で有限のmean Q30と、L／U両区間の有効性が必要。L下端>0かつU上端<0なら支持。L上端≤0またはU下端≥0なら不支持。その他は保留。mean(Q120)/mean(Q30)の実用帯(.8,1.25)を対象にし、個別比の平均、SD比、対称な「±25%」とはしない。
- いずれも、必要欠測・非有限・SE0の無効区間は保留。全R20×120の完備性を方法別に要求し、無効を0／非被覆へ置換せず、N30を縮めない。無関係な方法の無効をBCaへ波及させない。`conditional_`完全例参考は判定に使わない。個別Q30=0の比NAだけで主d／L／Uを無効にしない。
- 分布間の全体判定は両方支持なら支持、どちらか不支持なら不支持、その他は保留。6本99.5%は近似が妥当な場合の名目多重性配慮（union noncoverage上限3%）であり、有限N・歪み下での厳密保証ではない。
