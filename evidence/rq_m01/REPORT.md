## 問いと固定した設計

**問い：** 真の平均差と母標準偏差を揃えたとき、標本数と母分布の形は、未知分散の1標本両側t推論の区間幅・被覆率・第一種過誤率・検出力をどう変えるか。

正規母集団は `X=μ₀+σ(d+Z), Z~N(0,1)`、右に歪む母集団は `X=μ₀+σ(d+E−1), E~Exp(scale=1)` とした。いずれも真の平均は `μ₀+σd`、分散は `σ²`。中心化した後の後者を通常のガンマ分布とは呼ばない。

| 項目 | 実行前の固定値 |
| --- | --- |
| 母分布 | 正規・中心化指数の2種 |
| 1標本の観測数n | 5・20・100 |
| 真の標準化平均差d | 0・0.2・0.5 |
| master seed | 0・1・2 |
| 各セルの反復数B | 5,000 |
| μ₀・σ・α | 0・1・0.05 |
| 全体 | 54セル・270,000標本組・11,250,000観測 |

正本は実行前にコミットした [manifest.json](manifest.json)。manifestのSHA-256は `4d9fd6044277ebe6b2ba06c028869cfa680fa8c26d424eb9697a31d2aadd8348`、エンジン・ランナー・manifestを固定したソースcommitは [`f249efec49478b3d43fb68f8cb8d43b9f2ead58d`](https://github.com/Tone75/mathscape/commit/f249efec49478b3d43fb68f8cb8d43b9f2ead58d)。実行前照合で、作業中ソースとコミット内容、manifestのソースハッシュ、実行環境が一致することを確認する方式である。

乱数はNumPy `Generator(PCG64(SeedSequence(...)))`。分布IDは正規1・中心化指数2、entropyはmaster seed、spawn keyは `(distribution_id,n,d_low32,d_high32,trial_id)` とした。dは符号付きゼロを正規化したIEEE754 float64のビット列で符号化し、trial IDは0に固定した。α・B・セル実行順は系列選択に含めない。セルごとに1つの系列を用い、最大1,000反復の連続バッチで生成した。seedは系列の識別子であり、独立性の証明の代わりではない。このような系列分割の背景は [NumPy SeedSequenceの公式資料](https://numpy.org/doc/stable/reference/random/parallel.html)を参照。

推論関数に渡すのは標本・μ₀・αだけである。標本分散はddof=1、自由度はn−1、`SE=s/√n`、両側p値は `2*t.sf(abs(T),n−1)`、区間は `標本平均±t.isf(α/2,n−1)*SE` とした。棄却は表示丸め前の `p<α`、被覆は閉区間が**真の母平均**を含むかで判定した。CIと検定の数値的一致を検証するときだけ、`abs(T)` と臨界値が `atol=rtol=1e−12` で近い行を境界例として区別する。実際のp値・区間・棄却判定は変更しない。定義と参照テストには [SciPy ttest_1sampの公式仕様](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.ttest_1samp.html)を用いた。

各セルの率には95% Wilson区間、率と平均区間幅にはMonte Carlo標準誤差を付けた。幅の標準偏差はddof=1。Wilson区間は各セルの記述用区間で、54セル一括の合否範囲ではない。実装を [SciPyのWilson区間](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats._result_classes.BinomTestResult.proportion_ci.html)とも照合した。無効標本があれば分母Bに保持し、率・幅などの集計を未定義とし、そのセルを要調査とする設計である。

正規27セルについて、被覆と棄却の計54比較を調査対象とした。全体ε=0.001、各裾 `0.001/(2×54)` の二項分布分位点を、両端を含む保守的な調査範囲として事前登録した。棄却側の理論値は非心度 `√n*d` の非心t分布から求めた。[SciPy nct公式資料](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.nct.html)に対応するCDF/SFを使用し、この理論を非正規セルへ流用していない。

## H1〜H3の判定

**H1：今回の事前登録基準では支持。** 正規の全27セルで被覆数が調査範囲内となり、d=0の9セルの棄却数も範囲内だった。正規セルの被覆率は94.42〜95.74%、正規・帰無条件の棄却率は4.26〜5.44%。B=5,000における名目被覆数の調査範囲は4,681〜4,813、名目棄却数は187〜319だった。これは有限実験と正規理論の整合を示す結果で、理論の証明や全データ状況での保証ではない。

**H2：今回の事前登録基準では支持。** 正規の全9組の `(d,seed)` で、平均区間幅がn=5→20→100と厳密に縮小した。d=0.2・0.5の理論検出力はnとともに上昇し、全27正規セルの実測棄却数がそれぞれの理論調査範囲内だった。正規の被覆・棄却を合わせた54比較の調査フラグは0。個別セルの実測棄却率と理論値の絶対差の最大は1.17352パーセントポイントだった。一つの標本のp値や区間幅が単調になるとは主張しない。σ固定の場合、正規の区間幅の分布は真の位置dに依存せず、d間の実測幅の差は別々の乱数系列による揺らぎである。

**H3：事前に限定したn=5・d=0の基準では支持。** 中心化指数のseed 0・1・2で、棄却数は627・602・572とすべて上限319を超え、被覆数は4,373・4,398・4,428とすべて下限4,681を下回った。対応する正規3セルはすべて名目調査範囲内で、6セルとも無効0。ずれは全seedで過剰棄却・被覆不足という同じ向きだった。この名目範囲との比較は事前登録の記述的基準であり、非正規セルを正規理論の54比較へ追加していない。

n=20・100やd≠0の非正規結果は記述にとどめる。たとえば中心化指数・d=0ではn=100で被覆率が95%に近づいたが、これだけで「n=100なら妥当性が回復する」とは結論しない。n=100のd=0.2・0.5では、3seed集計の被覆率はそれぞれ93.96%・94.2933%だった。

## 限界と次の単一RQ候補

本実験は2つの母分布、3つのn、3つのd、3つのmaster seed、固定αに限定される。平均と分散が同じでも、歪度などの高次の形状は揃っていない。有限反復の率と幅にはMonte Carlo誤差があり、擬似乱数と浮動小数点を用いている。全セルを残したまま評価し、不都合なseedの除外や結果を得るための再抽選は行っていない。
