# RQ-M03｜Bootstrap端点の安定性と被覆不足を分ける

2026-11-08。事前固定した12原標本生成セルを1回実行し、全1,200原標本・24,000内側系列・108 seed別手法行を完了した。**事前の限定基準ではH1・H2・H3を支持**。B増加による端点の揺れの縮小、尾部警告との関連、最大Bでも残る小標本の被覆不足を、それぞれ別の量で確認した。

最大B=4,999を真値・無限Bの正解としていない。新成果はレビュー待ちで、Ownerによる新成果の受入や外部科学レビューを実施済みとは扱わない。承認済みのRQ-M02の仮説・結果・証拠は保持し、旧実験を再実行していない。

## 問い・固定設計・乱数

**問い：** 原標本を固定したとき、有限bootstrap回数Bと尾部解像度は、BCa区間端点の再標本化乱数による揺れにどう関係するか。また、Bを増やして端点が安定しても、小標本の被覆不足は残るか。

nは観測数、Rは独立原標本数、Kは原標本を固定した計算変動を測る系列数、Bは各系列の再標本化回数である。各分布×nのプール独立単位は**300原標本**。6,000区間やB回数を独立な母集団標本数として数えない。tは1原標本から一度だけ計算する対照で、k・Bに重複表示されても標本数は増えない。

乱数はPCG64／SeedSequence。entropy=master seed、spawn key=`(namespace,distribution_id,n,outer_id,purpose_id,inner_id)`。正規ID=1、中心化指数ID=2、原標本purpose=0・inner=0、bootstrap purpose=1・inner=0〜19。主namespaceは `0x4D3033`、smokeは `0x534D3033`。B・方法・α・表示順・バッチサイズを系列選択へ含めず、原標本・異なるouter・異なるkを分離した。[NumPy SeedSequenceの公式資料](https://numpy.org/doc/stable/reference/random/parallel.html)

同じi,kのpercentileとBCaは同じprefixを共有する。各Bのz0と調整分位点はそのprefixから再計算し、B=4,999のz0を流用しない。加速係数aとt対照は原標本だけに依存し、一度計算して保持する。

## 数理と評価単位

手法の定義はRQ-M02を維持した。tは標本分散ddof=1・自由度n−1。percentileはbootstrap平均の両側経験分位点で、補間はlinear。BCaはtieを半数として数えるz0、delete-one jackknifeと一致する加速係数a、調整分位点を使用する。同じbootstrap分布を再利用する参照テストは [SciPy bootstrap公開API](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.bootstrap.html)、分位点補間は [NumPy quantile公式仕様](https://numpy.org/doc/stable/reference/generated/numpy.quantile.html)と照合した。推論APIへ真の平均・母分散・分布ラベルは渡さず、真値0は評価側だけが用いる。

各原標本iの `se_i=s_i/√n`（sはddof=1）で尺度を揃え、同じ原標本・手法・BのK系列から次を計算した。

```text
SD_L,i = sd_k(L_i,k),  SD_U,i = sd_k(U_i,k)   （いずれもddof=1）
A_i(B) = sqrt((SD_L,i² + SD_U,i²)/2) / se_i
C_i(B) = mean_k I(L_i,k ≤ 0 ≤ U_i,k)
```

Aは「端点の再標本化SDを標本標準誤差単位で表した有限Kの指標」であり、真値に対するRMSEや推定量の標準誤差そのものではない。理論上の条件付きSDの不偏推定とも称さない。生の上下端点SDを別に示す。Cは各区間の被覆指示の平均であり、平均端点から新しい区間を作った被覆ではない。

端点ごとの尾部量は `tau=B×min(q,1−q)`。どちらかが10未満なら警告を記録する。警告は計算失敗や除外規則ではなく、原因の証明でもない。Bの適応的増加・fallback・クリップを行わない。

被覆・幅・警告は原標本内Kを平均した後に、独立原標本間のSDとMCSEを計算した。Kを独立な母集団標本としたWilson区間や `sd/√(R×K)` は使わない。必要な内側系列が一つでも無効なら、その原標本の主A・C等はNA。必要な原標本が欠ける確認的比較の主集計・判定もNA／保留とし、共同有効例だけの参考値は `conditional_` と明示する。今回は全原標本・全必要系列が有効で、欠測・無効数は0だった。

端点のMonte Carlo変動を評価する考え方は [Efron & Narasimhan (2020)](https://pmc.ncbi.nlm.nih.gov/articles/PMC7958418/)を参照した。本研究は論文のbcajackを実装したものではなく、独立K系列から変動を直接測る固定設計である。50%・0.02・93%という閾値も論文由来の普遍的基準ではない。

## 4確認量とH1〜H3

H1・H3は300独立原標本の平均±t(0.995,299)×SD／√300、H2は原標本単位のWelch区間を使用した。4量の99%区間による近似的な多重比較管理であり、厳密な同時保証とは称さない。分散0等で区間が未定義なら判定は保留。率の計算区間が[0,1]外へ出てもクリップしない。全条件の数値とseed別点推定は [hypotheses.json](hypotheses.json)、H2群別は [H2_groups.csv](H2_groups.csv) に保存した。

**H1：両nで支持。** B=4,999のAからB=199のAの半分を引いた平均Dは、n=5・20とも99%上限が0未満で、全seed平均も負だった。これは事前に定義した平均での半減条件を満たす結果である。すべての個別原標本で半減した、すべてのB段階で単調になった、理論上のSDを正確に推定したとは主張しない。

**H2：限定した関連を支持。** 分類にはB999のk=0〜9だけを用い、10系列中5回以上の警告でW=1とした。端点変動の評価は独立なk=10〜19だけから計算した。プール群数はW1=119、W0=181で、両群30以上。seed別は次のとおりで、各群5以上という条件も満たした。

W1の平均A_evalは0.139980、W0は0.107321。Welch標準誤差は0.00411088、Satterthwaite自由度は161.4623、99%区間下限0.021944は閾値0.02を超えた。全seed差も0.02を超える。分類と評価に同じ内側乱数を使っていないが、原標本の性質は群間で異なる。**警告が揺れを引き起こす因果効果の推定ではない。**

**H3：限定条件で支持。** 中心化指数n=5・B=4,999の平均Cは77.8833%、原標本単位MCSEは2.3634 pp、99%区間は[71.7565%,84.0101%]。上限は事前閾値93%未満で、全seed平均も閾値未満だった。端点の揺れが小さくなっても、この小標本パネルでは被覆不足が残った。無限Bでの被覆を確定したわけではない。

今回は4量すべてが必要な区間・seed・群数・完全有効条件を満たした。支持／不支持／保留の規則、H1のn別判定、欠測時の扱いは事前固定したもので、結果後に閾値や規模を変更していない。

## 保存データと独立監査

[panels/](panels/) の12 NPZは、`(original,B,method,inner)` 軸で下端・上端、z0、a、q、tau、valid／理由、尾部警告を保持する。方法順はt・percentile・BCa。各NPZに100原標本の値、outer ID、inner ID、B値、方法名、分布・n・seed・固定α・namespaceを含めた。原標本hashはlittle-endian float64のC順バイト列に対するSHA-256でIDと対応付ける。全bootstrap平均列や抽出インデックス列は保存していない。

[independent_audit.json](independent_audit.json) は主集計器をimportしない独立実装で保存原標本・端点診断から再計算した記録で、**不一致0**。1,200原標本のhash・SE・a・t参照、tとaの不変性、q／tau・警告、原標本単位のA／CとMCSE、全108 seed行・36プール行・10,800原標本行・8群行・48被覆差行、4確認量と判定を照合した。

## 限界と次の単一RQ候補

本結果は2母集団、n=5・20、固定平均・分散、α=.05、R=100×3seed、K=20、3つの有限Bに限定される。新規定理、bootstrap一般の優越、普遍的な推奨B、教育効果の実証ではない。原標本ごとのAには有限Kの推定変動があり、プール被覆にも独立原標本300件のMonte Carlo誤差がある。対照の正規tの点推定が名目95%からずれることも、それだけで理論の誤りを示さない。

Bを増やしても元の観測情報は増えない。端点の安定性、名目95%への被覆、区間の短さは別である。B=4,999を無限Bの正解と扱わず、H3の支持をB→∞の被覆へ拡張しない。警告と変動の関連を因果効果としない。個々の実現区間に真値が95%の確率であるとも説明しない。
