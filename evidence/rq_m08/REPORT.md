同じ原標本i・予算反復rの**同じ120系列**を3配分が共有する。各配分は重複なしで全120本を使い、配分ごとに別生成していない。同一予算は系列数・再標本数・抽出数の同一性で、同じwall時間を保証しない。共通生成と集計追加費用は一つの実行で実測し、配分別の速度ベンチマークとはしない。

## 推定量：各組の平方根を取ってから平均

```text
se_i = sample_SD_ddof1(x_i)/sqrt(20)
V_irpj = (var_k(lower) + var_k(upper)) / (2*se_i²)    全分散ddof1
A_irpj = sqrt(V_irpj)
T_irp  = mean_j(A_irpj)
M_ip   = mean_r(T_irp)
Q_ip   = var_r(T_irp)                               ddof1

d_i = mean_r(T_ir,P120 - T_ir,P30)
L_i = Q_i,P120 - .8*Q_i,P30
U_i = Q_i,P120 - 1.25*Q_i,P30
```

Tは **mean(sqrt(V))** であり、sqrt(mean(V))や先に120端点をプールする量ではない。P120だけは組が一つなのでsqrt(V120)となる。Qは1予算のTを測り直す反復分散であり、端点分散V、原標本間分散、群平均MCSEと別である。Q/RはR反復平均Mの条件付き分散の推定量として別記するが、主Qへ置き換えない。

各配分のSD_L／SD_U／Sは組ごとの端点SD／合成SDを**組間で平均**し、Ase=T、Apop=組平均S×√20、Vse=Vbar=組平均Vとして記録した。VseはT²ではない。原標本別・要約CSVのT／Ase列は対応するR平均でMと同じ意味になる。`miss_T`は非被覆方向Mbelow−Maboveであり、**予算推定値Tとは別の列**である。

理想的に系列がIIDで必要モーメントが有限なら、E[T_p|x]=E[A_K|x]、Var(T_p|x)=Var(A_K|x)/J。しかし有限Rの実測Qをこの理想式で置き換えていない。J平均化は有限Kに由来する期待値差を除去せず、ddof1も平方根後のSDを不偏にしない。[NumPy std公式資料](https://numpy.org/doc/stable/reference/generated/numpy.std.html) K120の真値性、無限Kの絶対偏り、c4補正の妥当性、RMSE、被覆改善は対象外である。

tは決定的対照でA／T／M／Q／d／L／U／gapを厳密に0とし、比較区間はSE0としてNA、Q比の0/0もNA。各原標本の実質1区間をR／120／3配分で独立に数えず、各配分のプール件数は30／分布とする。旧M05のtを含むK1安定性NAは保持し、0へ書き換えていない。

## 事前仮説・推論・欠測ゲート

主比較はBCaのP120対P30のみ。各分布N30／df29でd／L／Uそれぞれ両側**99.5%** t区間を作り、計6本に固定した。MCSEは原標本間SD／√30、t分位点はt(.9975,29)。原標本内の対応量を先に計算し、G／Lは独立群として別々に評価する。P60とseed別N10は記述のみで、追加のseedゲートはない。

| --- | --- |
| H1：平均移動は±.0025 Ase単位内 | d区間全体が厳密に(−.0025,+.0025)内なら支持。lo>.0025またはhi<−.0025なら不支持。接触・交差は保留 |
| H2：平均反復分散比は(.8,1.25)内 | L区間lo>0かつU区間hi<0で支持。L区間hi≤0またはU区間lo≥0で不支持。それ以外は保留 |

H2は**平均Q120／平均Q30**に対応する乗法的同等帯で、「±25%」でもSD比でも個別Q比平均でもない。個別Q30=0の比をNAにしても、その原標本のd／L／Uは定義可能なら保持する。個別比の未定義だけで必要主量を欠測扱いしない。

全R20×120の端点・診断を方法ごとに要求し、必要無効／非有限／se≤0は該当原標本の主量NA。計画N30を縮めず、当該分布の主判定を保留する。他方法の無効を完成したBCaへ波及させず、無効を0／非被覆へ変換しない。完全例参考は`conditional_`と分母を明示し、主判定に使わない。今回は必要全原標本／論理区間が完全有効で欠測0だった。

.0025と(.8,1.25)は本研究の事前の実用判断幅で、公的標準や理論・検出力計算の保証値ではない。6本の近似99.5%区間の和事象上界で非被覆率名目約3%以下を意図するが、各近似区間の妥当性が前提で厳密な有限標本保証ではない。N30、非正規・歪み、有限R／Kのノイズ、既知原標本再利用を限界として残し、結果で幅やN／Rを調整しない。

## Jgap＋Pgapと平方和分解

```text
Jgap = sqrt(mean_j V30) - mean_j sqrt(V30)
Pgap = sqrt(V120) - sqrt(mean_j V30)
T_P120 - T_P30 = Jgap + Pgap
```

今回はP30が4組平均なので、M07の先頭組選択差Rgapは存在しない。Jgap≥0は凹性による代数で、科学仮説の支持件数へ加えない。Pgapは分散プール差で正負があり、delta全体をJensen効果、Jgapを絶対偏りと呼ばない。

各端点で、4×30と2×60の平方和分解を両方照合した。

```text
119*s120² = 29*sum4(s30²) + 30*sum4((mean30-mean120)²)
119*s120² = 59*sum2(s60²) + 60*sum2((mean60-mean120)²)
```

全rの符号・分布・原標本r平均と99.5%記述区間を保存した。次の符号件数はN30×R20＝600予算反復／分布・方法の**記述**であり、独立原標本N600として検定したものではない。原標本平均のMCSE／区間はN30である。
