## 科学レビューと単一RQ

M07はB4999・測定反復J20を固定しK30→120を比べたため、1測定に使う再標本化量も4倍だった。Q120/Q30の低下だけでは同一予算の効率を示さない。M07のQ30は先頭30の変動で、4組平均の変動ではない。既知のQ30/4を実測したQ(4組平均)の代用にしない。

<b>RQ-M08：同じ原標本・B4999・1予算当たり120系列のもとで、30系列によるAse測定を4回平均する方法と、120系列による1回の測定は、平均値と測り直しの分散において実用的に同等か。60系列×2回はその中間としてどこに位置するか。</b>

予想：独立平均化とK増加がともに分散を減らすため同一予算では大差が小さくなる可能性がある。一方、Aseは分散の平方根なので、Jを増やしても有限Kの期待値の違いは消えない。これは検証前の見通しであり、同等性・単調性・最適配分を前提にしない。一次デルタ法によるおおよその1/(JK)関係も説明に留め、実験結果の代用にしない。

M07集計・分解を見て設計したことを明記。M07端点を並べ替えるだけの解析は探索的再解析であり、M08の事前固定検証には用いない。M08は同じ保存原標本に対する新規乱数系列であり、独立した新しい原標本による追試ではない。

## 推定量と識別範囲

原標本i、予算反復r、配分p=(J,K)、非重複組jについて、全標本分散はddof=1：

```txt
se_i = sample_SD(x_i) / sqrt(20)
V_irpj = [var_k(lower) + var_k(upper)] / (2*se_i^2)
A_irpj = sqrt(V_irpj)
T_irp = mean_j(A_irpj)
M_ip = mean_r(T_irp)
Q_ip = var_r(T_irp)

d_i = mean_r(T_ir,P120 - T_ir,P30)
L_i = Q_i,P120 - 0.8*Q_i,P30
U_i = Q_i,P120 - 1.25*Q_i,P30
```

Tは「各組の平方根を取ってから平均」。sqrt(mean V)や全120端点の分散へ先にプールする処理へ置き換えない。Qは1予算の推定値Tを測り直したときの反復分散。Q/RはR反復平均Mの条件付き分散の推定量として別表示できるが、主Qへ置換しない。端点分散V・原標本間分散・群平均のMCSEとも区別する。

対象は群の平均有限K推定値と平均条件付き反復分散。H2はmean(Q120)/mean(Q30)に対応し、mean(Q120/Q30)ではない。各原標本の比は0分母をNAとして参考のみ、検定に使わない。G/Lは独立群で、seed/ID一致を対応標本と扱わない。

理想的に全系列がIIDで必要モーメントが有限なら、E\[T\_p\|x\]=E\[A\_K\|x\]、Var(T\_p\|x)=Var(A\_K\|x)/J。ただし有限RのQには推定ノイズがあり、実測Q間の等式にはならない。J平均化は有限K由来の期待値差を除去しない。K120も真値ではない。無限Kに対する絶対偏り・RMSE・補正・被覆改善・普遍的最適配分は対象外。

## 事前仮説・判定

主比較はBCaのP120対P30のみ。各分布N30でd/L/Uそれぞれ平均±t(.9975,29)×SD/√30、両側99.5%近似t区間、計6本。各原標本内の対応量を先に作る。seed別N10は記述のみ。

<b>H1：平均の移動は±.0025 Ase単位内。</b> dの区間全体が厳密に(-.0025,+.0025)内なら支持。lo>.0025またはhi\<-.0025なら不支持。境界接触・その他は保留。

<b>H2：平均反復分散の比は(.8,1.25)内。</b> Lのlo>0かつUのhi\<0なら支持。Lのhi≤0またはUのlo≥0なら不支持。それ以外は保留。これは乗法的同等帯であり「±25%」やSDの同等帯ではない。主比較の平均Q30が正で有限であることを確認する。

H1/H2それぞれ両分布支持のときだけ全体支持、どちらか不支持なら全体不支持、その他保留。「平均」と「反復分散」の両方の同等性はH1/H2とも両分布支持の場合だけ述べる。部分支持と保留を隠さず、不支持を逆方向の優位性と自動解釈しない。P60を結果後に主比較へ昇格しない。

.0025はM07の測定手続き変更マージンを継承。.8/1.25はこの問いに対する事前の実用判断幅であり、理論・公的標準・検出力計算から保証された値ではない。M07の分散比に合わせて幅を調整しない。6本の近似99.5%区間の和事象上界は名目約3%以下を意図するが、近似の妥当性が前提で厳密保証ではない。N30・R20、非正規・歪み・原標本再利用・有限K期待値の違いを限界として残す。結果を見てN/Rや幅を拡大しない。

方法ごとに全R20×120の端点・診断が必要。必要欠測・非有限・se≤0は該当原標本の主量NAとし、計画N30を縮めず該当分布の主判定を保留。方法間は独立に完備性を判定。主比較SE0もNA/保留。無効を0や非被覆に置換しない。完全例参考はconditional\_と明記して主結論に使わない。tのA/T/Q/dは厳密0、比・比較区間はNA。旧K1の安定性NAを0に書換えない。
