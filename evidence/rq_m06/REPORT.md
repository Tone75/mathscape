# RQ-M06｜同じ保存標本でもBCa端点はどれだけ揺れるか

2026-11-09。受入済みM05の固定原標本1,200個を再利用し、新しい内側系列36,000本を1回だけ実行した。**H1の「B4999で平均Ase差に.01超の実用差が残る」は不支持で、指定した2分布・n20・α=.05・B4999・K30測定手続きの平均Ase差について±.01内の実用的同等性を支持した。H2の「B999から4999で両分布とも平均端点変動が25%超低減する」は支持された。** 原標本の新規生成0、再実行0、無効・欠測0、保存結果の独立実装監査は不一致0だった。

Aseの.01は**標本SEで規格化した端点変動の差**で、被覆率の1ppではない。揺れが小さくなることと被覆の正しさは別であり、B4999を無限Bの正解とはみなさない。本RQの新成果はOwnerレビュー待ち。外部科学レビューや受入・PR mergeを完了したとは扱わない。

## 固定規模・乱数・推論

| 項目 | 固定値・完了数 |
| --- | --- |
| 分布 | G=Gamma(1,scale=1)−1、L=M05の解析的標準化対数正規。両母平均0・分散1・歪度2 |
| 原標本 | n20、各seed 200／分布、seed0・1・2、各分布N600、全1,200保存原標本 |
| 推論 | α=.05の両側区間、t・percentile・BCa |
| 内側系列 | 原標本ごとK30、全36,000本、新しい原標本生成0 |
| B | 999／4,999。同一長4,999列の先頭999を共有 |
| 論理再標本処理量 | 179,964,000再標本組、3,599,280,000抽出インデックス |
| 論理区間 | 216,000。tは原標本ごと1回計算後B／Kへbroadcast |
| 原標本別集計 | 7,200行。seed36行、pooled12行 |

PCG64／SeedSequence、entropy=既存master seed。spawn keyは `(namespace,distribution_id,20,outer_id,1,inner_id)`、主namespace `0x4D3036`、smoke `0x534D3036`、G1／L2、outer0〜199、inner0〜29。purpose0の原標本生成を禁止した。B・方法・UI・バッチをキーに含めず、分布間はIDが同じでも独立群、同一原標本内のB／方法差だけを対応比較とする。[NumPy SeedSequence公式資料](https://numpy.org/doc/stable/reference/random/parallel.html)

各innerで1回だけ4,999平均列を生成し、両方法と両Bへ共有する。乱数のindices生成dtypeは明示的int64。保存監査対象だけuint8へ可逆変換する。t・a・標本SEは原標本から1回計算し共通だが、z0・調整qは各Bのprefixから再計算する。受入実装のddof1、linear分位点、半数tie、delete-one jackknife a、BCa有効性規約を変更していない。真値・母数・分布ラベルを推論APIへ渡さない。

調整q／分母が無効なら理由付きNA、fallback・qクリップ・適応Bなし。いずれか端点の `tau=B*min(q,1−q)<10` は警告として保持し、除外しない。同一bootstrap分布に対するpercentile／BCaは決定的fixtureと [SciPy bootstrap公開API](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.bootstrap.html) で参照照合した。公式APIの `standard_error` はbootstrap統計量分布のSDで、今回の繰返し計算間の端点SDとは異なる。

## 指標・推論単位・判定規約

```text
各原標本i、B、方法についてK30の端点を集計：
SD_L = sd_k(lower), SD_U = sd_k(upper)       ddof=1
S    = hypot(SD_L,SD_U)/sqrt(2)
se_i = sampleSD_ddof1/sqrt(20)
Ase  = S/se_i
Apop = S/(1/sqrt(20))                       評価層のみ母分散1を使用
Vse  = Ase²                                記述指標
```

Aseは標本SEに対する**端点の計算変動**で、平均推定のSE、bootstrap平均のSD、誤差やRMSEではない。全原標本の端点を混ぜてSDを求めず、各原標本内でK30のSDを作ってから原標本間で平均する。平均Aseは有限K30の測定手続きの対象であり、sqrtを含むため理想的な条件付きSDの不偏推定と主張しない。Vseも保存するが主判定への差替え・補正・無限K外挿を行わない。

**tは決定的対照なのでK30のSD_L／SD_U／S／Ase／Apop／Vse=0。旧M05はK1なので、tを含む条件付き安定性NAの表示を維持する。** tのbroadcastを30個の独立区間として数えず、各B／分布の実集計区間数は原標本数600とする。同じtを両B欄に表示しても原標本ごとの計算は一度である。

独立推論単位は原標本、各分布N600。MCSEは原標本別量のSD／sqrt(N)、記述平均は原標本単位99%t区間、分布差は独立Welch 99%区間（ddof1、Satterthwaite自由度）。K30やBをNへ加えない。対応差は同一原標本の差を先に計算する。[SciPy Welch参照API](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.ttest_ind.html)

これらは保存されたIID原標本を結果によらず固定IDで選んだモデルに基づく**原標本間の近似区間**で、K30推定ノイズを含む。固定された1,200原標本だけを条件とする内側乱数のみの区間ではない。seedは乱数管理ブロックで、独立した実験環境による追試ではない。全seed結果を記述するが、追加の方向ゲートは置かない。

| 主対象 | 事前固定規則 |
| --- | --- |
| H1：BCa B4999のΔAse=L−G | 99%独立Welch区間がlo>.01またはhi<−.01なら実用差支持。lo>−.01かつhi<.01なら実用差不支持かつ範囲限定の実用同等性支持。接触・交差は保留 |
| H2：各分布D=Ase4999−.75*Ase999 | 同一原標本のDの99%t区間でhi<0なら25%超低減を支持、lo≥0なら不支持、それ以外は保留 |
| H2全体 | 両分布支持だけ支持。どちらか不支持なら全体不支持、残りは保留 |
| 必要データ無効・欠測・非有限、se_i≤0、主比較SE0 | 該当主対象はNA・保留。H1はBCa4999の全600／群、H2は該当分布のBCa両B全600×K30を要求 |

無関係なBや他方法の欠測で完成した主対象を無効化しない。全必要分母を保持し、無効を非被覆0へ変換しない。完全例だけの参考は`conditional_`と明示して主判定に使わない。今回は全必要データが完了したため参考値と主値は一致した。

確認的な近似99%区間はH1の1本、H2の2本の計3本に固定した。Bonferroniの和で非被覆率約3%以下を意図した設計であり、厳密な有限標本保証ではない。.01や25%は本RQの設計値で、公式資料が推奨する普遍的閾値ではない。

## 解釈の限界と次の単一RQ候補

支持されたのは、この2分布・n20・α=.05・B999／4999・有限K30という測定手続きの**平均Ase**の低減と限定的な平均差の同等性である。個別原標本が必ず安定、計算変動0、差が厳密に0、無限B／Kの理想端点へ一致、偏りが消える、95%被覆が改善するという保証ではない。K30に由来するsqrtの有限K測定ノイズや偏りを分離・補正したとは主張しない。

母平均・分散・歪度は同じでも、G／Lは尖度・尾・支持域も異なる。観測差を尖度や尾だけの単独因果効果と解釈しない。M05を知って設計した保存部分パネルの再利用であり、新しい独立母標本での再現・他の分布族・n／αへの一般化・検出力保証は別課題。率・幅・Vse・警告の記述を主仮説へ昇格させず、結果に応じた除外／追加抽選も行わない。

**次の単一RQ候補：** 固定原標本と固定Bにおいて、Kの有限性が平均Aseの測定精度・sqrtに伴う偏りへどの程度影響するか。今回K30の対象を理想的な条件付きSDと同一視できない点を扱う候補で、別の事前登録・評価法・予算が必要となる。現在の結果を再抽選するためのR／K追加ではなく、現時点では設計・実装・実験を実行しない。
