## 同じ標本を使う3手法

推論APIが受け取るのは原標本・bootstrap平均列・αだけで、真の平均・母標準偏差・母分布ラベルを渡さない。3手法で原標本を共有し、percentileとBCaでは同一の999個のbootstrap平均を共有する。

- **t区間：** 既存の標本分散ddof=1、自由度n−1、`平均±t臨界値×s/√n` を再利用した。[SciPy ttest_1samp公式仕様](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.ttest_1samp.html)
- **percentile区間：** 共有bootstrap平均列のα/2・1−α/2分位点。補間はNumPy `method='linear'` に固定した。[NumPy quantile公式仕様](https://numpy.org/doc/stable/reference/generated/numpy.quantile.html)
- **BCa区間：** bias correctionは `z0=Φ⁻¹((#小さい+0.5×#等しい)/B_boot)`。加速係数は、平均からの偏差をc_iとして `a=Σc_i³/[6(Σc_i²)^(3/2)]`。delete-one jackknifeの別式と照合した。調整分位点は `Φ[z0+(z0+z_p)/(1−a(z0+z_p))]`。同じbootstrap分布をSciPy公開APIで再利用し、端点を独立に照合した。[SciPy bootstrap公式仕様](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.bootstrap.html)

定数・非有限標本、非有限z0／a、不正な調整分位点などは理由付き無効とする。BCaが未定義でもtやpercentileへ置き換えず、都合のよいクリップもしない。有限な経験分位点q=0／1を使用する場合を含め、いずれかの端点で `B_boot×min(q,1−q)<10` なら尾部解像度警告を記録する。警告による除外やB_bootの自動増加は行わない。

無効がある方法では、総数・有効数・無効数を保ち、主被覆率・主幅集計をNAとする。対応差も無効があれば主推定をNAとし、共同有効例の参考値には `conditional_` を付ける。無効を被覆失敗に数えたり、黙って分母から除いたりしない。今回は全方法の全区間が有効だった。

## 事前の5判定量とH1〜H3

率の水準には99% Wilson区間、対応した被覆指示差・幅差には `平均±z(0.995)×MCSE`、`MCSE=sd(対応差,ddof=1)/√6000` を使用した。z(0.995)=2.5758293035。5量に対するBonferroni型の近似的な全体95%判定で、正規近似を使う差の区間を含むため厳密な同時保証とは称さない。各seedの点推定にも、それぞれの閾値と同方向であることを要求した。

全条件を満たす場合を支持、少なくとも一つの判定区間が閾値の反対側に完全にある場合を不支持、それ以外の閾値跨ぎ・seed方向混在・無効／不完全は保留とする。正規t参照が未解決なら最終科学判定を確定しない。次表の差の「pp」はパーセントポイント、幅差は標準化単位である。

| H1：n=5、幅percentile−t | −0.838935 | [−0.855631, −0.822238] | 区間上限<0 | −0.836697・−0.817170・−0.862937 | 支持 |

**H1：限定条件で支持。** 中心化指数n=5のpercentile区間はtより平均で約0.839短く、被覆率は9.8ポイント低かった。幅差と被覆差の99%区間はともに事前閾値を満たし、全seedも同方向だった。短さだけを性能向上と扱えないことが、この比較で観測された。

**H2：保留。** BCa−percentileの被覆差は生の比率で0.0103333333、99%判定区間は **[0.0043017566, 0.0163649101]** で、事前閾値0.01を跨ぐ。seed別の差も0.005・0.0095・0.0165と閾値に対して混在する。BCa被覆率の上限<0.96という補助条件は満たすが、要求した「1ポイントを超える改善」の条件を満たしたとはいえない。区間全体が反対側にあるわけでもなく、不支持とは確定しない。点推定の改善を、校正成功やBCaの一般的優越へ読み替えない。

同じn=20条件の外した側を見ると、percentile→BCaで下への非被覆率は8.2667%→6.1667%へ減る一方、上への非被覆率は1.7333%→2.8000%へ増えた。両側を合わせた純被覆差が約1.0333ポイントであり、一方の側だけを見て改善幅を報告しない。

**H3：限定条件で支持。** 中心化指数n=5のBCa被覆率は80.2333%、99%上限81.5239%で、93%を下回る。全seedの点推定も閾値未満である。補正を加えても、この小標本条件の情報不足と被覆不足が解消したとはいえない。

## 再現手順と追加実行の制約

以下は手順の記録であり、掲載は追加実行の許可ではない。このレポートの作成・監査では原標本やbootstrap平均を生成せず、保存結果だけを読み取った。実際のコード不具合を修正する場合だけ、原因・旧ソース・旧結果・修正版を保存した別attemptで最大1回、主実験の累計wall≤600秒という制約を維持する。不支持・保留・期限超過を再実行理由にしない。

再現が許可された場合は**新しいclone**を用いる。既存の作業コピーをresetしない。ランナーはHEADと指定した完全SHAが一致し、ソース・manifest・実行環境が事前記録と一致することを要求する。既存のattempt／結果は上書きを拒否するので、新規出力先を指定する。

```bash
git clone https://github.com/Tone75/mathscape.git mathscape-rq-m02-reproduction
cd mathscape-rq-m02-reproduction
git switch --detach 2496eb06d77593e8ea2f19834de3b7aed2675a07
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m pytest -q
python scripts/run_bootstrap_benchmark.py --run \
  --manifest evidence/rq_m02/manifest.json \
  --output evidence/rq_m02/reproduction \
  --source-commit 2496eb06d77593e8ea2f19834de3b7aed2675a07
```

環境の不一致で事前照合に失敗した場合は、その状態を記録する。元のmanifestや旧結果を書き換えて照合を通過させない。スモークも今回1回を実行済みで、この再現手順に追加して自動実行するものではない。

## 限界と次の単一RQ候補

今回評価したのは、2母集団・3標本数・固定d=0・α=0.05・有限B_boot=999の平均区間手続きである。bootstrap一般、非正規分布一般、全n=100の振る舞いへ拡張しない。正規対照のn=5でもbootstrap区間の被覆は名目95%より低く、中心化指数n=100の被覆も全手法で名目95%より低かった。nが大きいという理由だけで校正済みとはしない。

反復した再標本化は元の観測情報を増やさない。尾部解像度警告が多いBCaでは、有限bootstrapの近似も結果の一部である。本実験はB_boot→∞への収束や、内側Monte Carlo誤差を独立に分離する設計ではない。外側MCSEを内側bootstrapだけの誤差と解釈しない。

短い幅、名目被覆への近さ、数値計算できることは別の性質である。各実現区間に真値が95%の確率であるとは説明しない。bootstrap区間にt由来のp値や検出力を付けず、幅だけで方法の優劣を順位づけしない。本研究は既知の手法の条件・限界を探索する数値実験であり、新規定理や教育効果の実証ではない。

**次の単一RQ候補：** 同じ小標本の中心化指数データで、有限B_bootによる尾部解像度はBCa区間の端点安定性をどう変えるか。別の事前登録と計算枠を定める候補として提案するだけで、今回は実装・追加実験を行わない。
