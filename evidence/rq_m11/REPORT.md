# RQ-M11｜全通りを数えた基準から、どれだけずれる？

M10の保存n5原標本60個とB4999の保存144,000系列を再解析した。**主仮説H11-EはGで21/30（70%）、Lで22/30（73.3333%）が基準内で、必要な27/30に届かず、両群・全体とも記述的不支持（not_supported）だった。** 基準は「上下両端点の保存2400系列RMSEが、それぞれ標本SEの0.10以内」。全参照・必要系列が有効かつ完備で、無効・欠測・判定不明0だった。独立数値監査は不一致0で完了している。

これは固定30標本と保存系列についての設計上の判定で、母集団の90%保証やBCaの母平均推定精度の検定ではない。0.10SEは「推定精度10%」ではなく、**本仕様の全列挙参照からの計算端点のずれ**である。M10の配分同等性H1／H2は保留のまま保持し、その保留の因果的説明や配分の優劣に読み替えない。

主解析1回・主再試行0、新原標本0・新bootstrap乱数系列0・PRNG再生0・追加smoke0。独立監査は2起動で、初回は入力一覧の照合に実装上の漏れがあり数値照合前に停止した。原因と元結果を保全し、監査の一覧確認を修正した2回目が全件一致した。主解析は再実行していない。

## 全列挙参照の意味と逆CDF

添字位置`(j1,...,j5) in {0,...,4}^5`をbase5順で1回ずつ列挙し、各順序付き再標本の確率を1/3125とした。1標本3125行、全60で187,500行・937,500添字。B3125個を復元抽出する操作とは異なる。

参照は「保存binary64標本とM10の平均計算規約を固定した、計算機上の条件付き有限分布」である。平均は元の順序の`np.mean(x[indices],axis=1)`、元標本平均thetaもM10と同じfloat64規約を維持した。原観測の並べ替え、丸め、jitter、iscloseによるtie追加をせず、±0は数値的に等しいatomとして扱う。

n5の個数ベクトルは126個だが、等重みではなく`5!/(c0!...c4!)`のmultinomial重みを持つ。同じ個数でも加算順によりbinary64平均が異なり得るため、代表平均1個×重みで参照を作らない。3125平均を全て計算し、数値的に同じbinary64値だけを整数頻度へ集約した。保存支持点数はG141〜268、L174〜343で、126代表値への圧縮とは別の対象である。

```text
F*(t) = count(y_s <= t)/3125
p* = [count(y_s < theta)+0.5*count(y_s == theta)]/3125
z0* = ndtri(p*)
a = 元標本centered/maxabs正規化による受入済み加速度
q*_e = ndtr(z0* + (z0*+z_e)/(1-a*(z0*+z_e)))
E*_e = generalized_inverse_CDF(F*,q*_e)
```

z_l=ndtri(.025)、z_u=−z_l。aは元標本だけから再計算してM10保存値と照合し、列挙列から計算しない。z0*は全3125のless／equalから計算し、有限Bのz0を流用しない。全列挙equal数はG24〜120、L8〜120だった。

主分位点は0<q≤1で累積質量が初めてq以上となる最小支持点。q=0は最小、q=1は最大。qのbinary64値の分子・分母を取り出し、`cumulative_count*q_den >= q_num*3125`を整数比較する。浮動小数の`ceil(3125*q)`による境界丸めを避け、支持点・頻度・累積個数、選択atom、左右CDF、qとの距離のfloat値と正確な有理数表現を保存した。

同じ3125列・同じq*にlinearを適用したE_linear*も別に保存した。主参照E*をlinearへ置き換えず、重み付き126代表点へlinearを適用しない。実数算術・母集団真値や、無条件に必ず到達するB→∞の極限値とは呼ばない。

## 誤差量・判定・無効と警告

標本SEは`S=SD(x,ddof=1)/sqrt(5)`。各保存系列s=(r,k)・端点eについて次を求めた。

```text
delta_s,e = (E_M10_s,e-E*_e)/S
b_e = mean_s(delta_s,e)
v_e = mean_s((delta_s,e-b_e)^2)       # ddof0
r_e = sqrt(mean_s(delta_s,e^2))       # 保存2400系列の実測RMSE
e = max(r_lower,r_upper)
pass = 全必要参照と2400系列が完備・有効 かつ e<=0.10
```

bは符号付き平均ずれで、正は保存端点が参照より大きい方向、負は小さい方向。真の期待バイアスの既知値ではない。SDはsqrt(v)・ddof0で、原標本SEや原標本間SDと区別する。RMSEは符号を失う二乗平均で、保存2400系列の実測値であり真の条件付き期待RMSEとは区別する。ddof1へ置換せず、ddof0で`r²=b²+v`を照合した。

各群全30標本が有効・完備なら、上下両端点RMSE≤.10SEを同時に満たす標本が27以上で記述的支持、26以下で記述的不支持。必要無効・欠測・SE不正がある群はN30を縮めず保留、conditional_参考で判定しない。閾値接触は≤で合格。丸め前で判定し、監査許容差でpassを増やさない。全体は両群支持なら支持、どちらか不支持なら不支持、それ以外は保留。

今回は主完了・独立監査passed／mismatch0を確認したため、保存computed判定を公開上の記述結果として読める。未完了／監査不一致では科学判定未検証として保留する。新たなt区間・p値・母集団推論は追加していない。0.10と90%はM10既知後に選んだ本診断の設計値で、公的標準・検出力保証ではない。

非有限z0／a、非正補正分母、非有限・範囲外・順序外q、非有限端点、SE不正などは方法別NA。BCa無効をpercentileへ波及させない。有効q=0／1や小さいtail massは警告で除外せず、clip／fallback／適応Bなし。全列挙の`3125*min(q*,1-q*)<10`警告と、有限Bの`4999*min(q_B,1-q_B)<10`警告を別項目にした。tにはbootstrap参照との誤差判定を作らず、保存対照・旧A／T／Q=0・旧NAを保持する。
