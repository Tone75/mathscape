# 独立監査の入力一覧修正

最初の監査は入力ファイルを個別にハッシュ照合した後、入力一覧の集合比較で停止した。主の固定manifestは受入済みM10の保存ファイル・ソースとパッケージ初期化ファイルを合わせた77件を記録していた。監査が組み立てた期待集合は76件で、`mathscape/__init__.py` を欠いていた。合成fixtureも同じファイルを省いており、固定前の結合テストはこの誤りを検出できなかった。

修正は期待集合に同ファイルを必須として加え、fixtureの入力構成にも加える。ファイル集合の厳密一致と、各ファイルのGit blobおよびSHA-256照合を保持する。最初の標準エラー、計測記録、全保存成果の修正前SHA-256、固定時のソースを参照できる。主解析の入力・出力・科学計算・判定・許容差を維持し、修正版は保存成果の読み戻し監査だけを行う。
