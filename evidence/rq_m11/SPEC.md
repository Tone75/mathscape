## 全列挙参照：意味と数値契約

原標本を固定し、添字ベクトル `(j1,...,j5)∈{0,...,4}^5` を各1回、計5\^5=3125通り列挙する。各順序付き再標本の確率は1/3125。全60標本で187500行、937500添字。復元抽出でB=3125個引く操作とは異なる。

**本RQの参照対象は「保存binary64標本とM10の平均計算規約を固定した、計算機上の条件付き有限分布」**である。組合せは全数だが、実数算術・母集団真値の厳密解ではない。全列挙の平均はM10の `np.mean(x[indices],axis=1)` と同じdtype・行内順序・reductionを使用し、元の標本平均もM10の保存／計算規約に一致させる。

n5には126個の個数ベクトル `c0+...+c4=5` があるが、これらを等重みとしてはならない。重みは `5!/(c0!…c4!)`。さらに同じ個数でも順列による浮動小数の加算差があり得るため、代表平均1個へ重みだけ掛けて主参照を作らない。異なる順序の全3125平均を評価し、同じbinary64値を集約する場合だけ整数頻度を合算する。±0は数値的等値として扱う。

全列挙列を `y_s`、元のfloat64標本平均を `theta_i` とする。

```txt
F_i*(t) = count(y_s <= t) / 3125
p_i* = [count(y_s < theta_i) + .5 count(y_s == theta_i)] / 3125
z0_i* = ndtri(p_i*)
a_i = M10と同じ原標本だけからの安定化加速度
z_l = ndtri(.025), z_u = -z_l
q_i,e* = ndtr(z0_i* + (z0_i* + z_e)/(1-a_i*(z0_i*+z_e)))
E_i,e* = generalized_inverse_CDF(F_i*, q_i,e*)
```

aは元標本のcentered/maxabs正規化と三次和／二次和から再計算してM10保存値と照合。全列挙平均列からaを計算しない。半数tieはfloat64の厳密な `==` を維持し、iscloseによるtie追加・丸め・jitter・標本の並べ替えをしない。主z0はM10の有限Bのz0を流用せず、全3125から計算する。

主分位点は線形補間ではなく、0\<q≤1で累積質量が初めてq以上になる最小支持点。q=0は最小値、q=1は最大値。累積個数とqのbinary64値の有理数表現を整数比較し、浮動小数の `ceil(3125*q)` の丸めで境界を越えない実装にする。支持点と累積整数頻度、左右CDF、qと両境界の距離を保存する。

非有限z0/a、非正補正分母、非有限／範囲外／順序外q、非有限端点等の無効規約を継承する。q=0/1、少ないtail massは警告で除外しない。qクリップ・代替手法fallback・適応Bは禁止。全列挙側のtail massと、保存有限Bのtail\_count警告を別項目にする。

離散分布の境界では極限の振舞いに注意が必要なため、E\*を無条件に「B→∞で必ず到達する真値」と呼ばない。本仕様で定義した決定的な条件付き参照端点である。

## 主量とH11-E

各原標本i・端点e・保存系列s=(r,k)について、S\_i=SD(x,ddof1)/sqrt(5)を固定する。

```txt
delta_i,s,e = (E_M10_i,s,e - E_i,e*) / S_i
b_i,e = mean_s(delta_i,s,e)
v_i,e = mean_s((delta_i,s,e - b_i,e)^2)   # ddof=0
r_i,e = sqrt(mean_s(delta_i,s,e^2))       # 保存2400系列の実測RMSE
e_i = max(r_i_lower, r_i_upper)
pass_i = finite/complete and e_i <= .10
c_D = count(pass_i), planned_N_D = 30
```

**H11-E：各分布でc\_D≥27/30。上下両端点のRMSE≤0.10標本SEを同時に満たす原標本が90%以上ある。**

- G/L別判定：全30標本の必要参照・2400系列が有効で完備なら、27以上で記述的支持、26以下で記述的不支持。
- 必要無効・欠測・SE不正がある群は保留。Nを縮小せず、確認できたpass数・無効数・missing数を併記する。完全例の参考値はconditional\_と明記し主判定へ使わない。
- 全体：両群支持なら支持、どちらか不支持なら全体不支持、それ以外は保留。未完了／監査不一致の実行は科学判定未検証として保留し、確定集計に混ぜない。
- 0.10と90%はこの保存データ診断の設計上の許容値。M10結果を知った後に選んでおり、公的標準・検出力保証・母集団への90%保証ではない。M10の±.0025やQ比の帯とは異なる尺度なので流用しない。
- 閾値接触は≤として合格。丸め前の保存値で判定し、表示丸めや監査許容差でpassを増やさない。閾値の近傍値は余裕 `.10-e_i` とともに報告。
- これは固定30標本と保存2400系列に関する有限データ判定。t区間・p値・新たな母集団推論は追加しない。2400や144000を独立原標本数としてNにしない。真の条件付き期待RMSEと有限系列の実測RMSEを区別する。

bは保存系列の符号付き平均ずれで、真の期待バイアスの既知値ではない。r²=b²+vをddof0で照合する。ddof1 SDを補助表示する場合は2400/2399の補正を明記。恒等式成立は実装検査で、科学仮説の支持に加えない。

## 規約差・記述診断

全3125個のソート済み平均列にM10のlinear規約を適用した端点`E_lin` も、同じ `q` で保存する。重み付き126代表点にlinearを適用しない。主参照E\*は置き換えない。

```txt
E_M10 - E* = (E_M10 - E_lin*) + (E_lin* - E*)
```

第1項は保存有限B端点と3125要素linear参照との差、第2項はこの有限参照上の分位点規約差である。第1項を純粋なMonte Carlo誤差や独立な因果成分と呼ばない。分散・二乗誤差の分解に使う場合は交差項を省かず、主RMSEは必ず直接E\_M10−E\*から計算する。

各標本・各端点についてb、r、sqrt(v)、平均絶対ずれ、絶対ずれp50/p95/max、q\*、q\_Bの範囲、z0\*、a、tie/less数、支持点数と選択atom質量を記述する。分位点の要約p50/p95にはlinearを明示してよいが、主参照の逆CDFと区別する。G/L各30のe\_i分布・合格率・全ID表を保存する。

percentileにはq=.025/.975の同じ全列挙CDF参照とlinear参照を使い、同じ誤差量を記述する。追加仮説は設けない。tにはこのbootstrap参照との誤差判定を作らず、既存のA/T/Q=0や旧NAを保持する。BCaとpercentileで無効を相互に伝播させない。

代表例は結果を見て恣意的に選ばず、各群e\_i最大（同点時seed,outer昇順）・最小（同順位規約）を固定ルールで提示。BCa警告の有無による記述は除外や新判定ゲートにしない。
