# RQ-M12-v1｜同じ全列挙分布上のBCa端点移動

固定仕様本文と受入・実行条件。2026-11-20 JST。[Notion正本](https://app.notion.com/p/41d251c5f0858163a7ace7ddcd36f1d3)

## 問いと主仮説

M11で測ったのは、保存されたBCa端点と全列挙参照端点の総ずれだった。両端の実測RMSEが0.10標本SE以内に収まったのは標準化ガンマ（G）21/30、標準化対数正規（L）22/30で、上端の群平均RMSEが両群で大きかった。percentileは両群29/30だった。この観測から、BCaが選ぶ確率の揺れが端点にどう写るかを一つの問いとして調べる。

**RQ-M12**　同一原標本の全列挙分布を固定し、全列挙から得たBCa補正確率 `q*` を、B=4,999の各保存系列で得た補正確率 `q_B` に置き換えたとき、下端と上端は何標本SE動くか。

**H12-Q**　G・Lの各30原標本のうち27以上で、上下各端点について2,400系列にわたる移動の実測RMSがともに0.10標本SE以内に収まる。0.10と27/30は、M11で測った総ずれと同じものさしで読めるよう採用する。M11の結果を知った後の保存データ再解析であり、M12の数値を初めて計算する前に手順と判定を固定する。

## 入力と計算

- 受入済みM11提出HEAD `0deb14fa313dc27380afbb43e6b132386aa40206`。同HEADの `evidence/rq_m11/references/` と `comparisons/`、M11のmanifest・receipt・標本別指標、必要なM10の原標本と保存panelを用いる。(G/L × seed 0..2 × outer 0..9) の全60標本、n=5。各標本R20×120=2,400共通系列、α=.05。計144,000系列・BCa上下288,000端点。P30/P60/P120の共有系列は一度だけ数える。
- referencesの `support, frequency, cumulative, means, q, E_cdf`、comparisonsの `saved_q, saved_endpoint, saved_valid, observed, delta` とM10のwarningを、受入済みschemaで結ぶ。キー・軸・dtype・ID・hashは実ファイルと照合して固定。方法順BCa/percentile、端点順lower/upper、系列順 `r*120+k` を検証する。qの表示値やCSVの丸め値を計算に使わない。
- 原標本iの条件付き逆CDFをQとする。保存binary64の支持点と正の整数頻度を使い、頻度総和は3,125。0<q≤1で `q=num/den` をbinary64の正確な整数比から取得し、`cumulative[j]*den >= 3125*num` を最初に満たす支持点を選ぶ。q=0は最小、q=1は最大。重複値・±0はM11規約を継承し、近い値を丸めてまとめない。`Q(q*)` が保存参照端点・その支持点と一致することを確認する。
- 次の式を各原標本i、系列s、端点eに適用する。SはM11と同じ `SD(x,ddof=1)/sqrt(5)`。分母が正で有限であることを確認する。

```txt
A = Q(q*)                          # M11の全列挙参照端点
C = Q(q_B)                         # 同じ分布から保存確率で選ぶ端点
Y = 保存された有限Bのlinear BCa端点
g = (C - A)/S                      # 主量。確率を置き換えたときの移動
h = (Y - C)/S                      # 同じq_Bでの残差
d = (Y - A)/S                      # M11の総ずれと直接照合
r[i,e] = sqrt(mean_s(g^2))
u[i] = max(r[i,lower], r[i,upper])
```

## 判定と解釈

- 原標本合格は丸め前の `u[i] <= 0.10`。分布別に必要な30標本×2,400系列が完備・有効なら27以上で記述的支持、26以下で記述的不支持。必要値無効／欠測のある群は保留とし、合格確認数／計画30、無効・欠測・判定不明の内訳を保存する。両群支持で全体支持、少なくとも一群不支持なら全体不支持、その他は保留。入力破損・監査不一致・未完走時は未検証として確定判定を出さない。
- q=0/1・低tail-count等の有効な警告は含める。保存無効、確率順序不正、範囲外、非有限等を理由別に扱う。クリップ・代替値・系列補充は行わない。計画Nは各群30。2,400は同一標本の計算反復数。
- **同じ支持点に留まる頻度と、実際に動いた距離を分けて報告する。** 各標本・端点でqの差、同じ／下へ／上へ移った件数と率、gの符号付き平均・RMS・絶対値p95/最大、移動時の平均絶対移動（0件ならNA）、各標本のuと余裕 `0.10-u` を保存。原標本ごとに集計してG/L・上下別に要約し、4分類（M11合否×M12合否）をID付きで示す。qが変化しても同じ段に留まる場合、ごく近い別の支持点に移る場合を識別できる表示にする。
- 診断では `d=g+h` と `mean(d²)=mean(g²)+mean(h²)+2 mean(g*h)` を端点ごとに直接照合する。交差項は符号付きで保存する。hには有限Bの経験分布と分位点補間規約の差がともに入り、同一系列のgとhは依存し得る。各項から因果的寄与率は推定できない。固定確率のpercentileを通したg=0は実装確認にだけ使う。
- 結論の対象は受入済み60原標本・保存系列の計算端点。母平均の被覆率、一般のn=5、M10が保留となった原因は別の問い。既知のM10 H1/H2は両群保留、M08/M09はn=20の固定条件で支持。M11不合格標本だけに絞らない。
