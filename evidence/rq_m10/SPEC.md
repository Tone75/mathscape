## 推定量と主仮説

```txt
SE_i = SD(x_i,ddof=1)/sqrt(5)
V_irpj = [var_k(lower,ddof=1)+var_k(upper,ddof=1)]/(2*SE_i^2)
A_irpj = sqrt(V_irpj)
T_irp = mean_j(A_irpj)
M_ip = mean_r(T_irp)
Q_ip = var_r(T_irp,ddof=1)
d_i = mean_r(T_ir,P120 - T_ir,P30)  # M120-M30と数学的に等価。M09の演算順を維持
L_i = Q_i,P120 - .8*Q_i,P30
U_i = Q_i,P120 - 1.25*Q_i,P30
```

Tは平方根の後に平均し、sqrt(mean V)に置換しない。Qは1予算のTの反復分散で、Q/R、端点分散V、原標本間分散と区別する。H2はmean(Q120)/mean(Q30)の帯であり、個別比の平均、SD比、対称な「±25%」ではない。

各分布N30のd/L/Uに平均±t(.9975,29)\*SD/sqrt(30)の両側99.5%近似t区間を適用する。主6区間、丸め前で判定する。

| 仮説 | 支持 | 不支持 | 保留 |
| --- | --- | --- | --- |
| H1：平均Ase差が±.0025内 | dの区間全体が厳密に(−.0025,+.0025)内 | lo>.0025 または hi\<−.0025 | 境界接触・交差・その他 |
| H2：平均反復分散比が(.8,1.25)内 | Lのlo>0 かつ Uのhi\<0 | Lのhi≤0 または Uのlo≥0 | その他 |

H2はmean Q30が正・有限、L/U区間が有効であることが前提。主比較区間のSE0はM09規約どおりNA／保留。個別Q30=0による個別比NAだけで、有効なd/L/Uを無効化しない。各仮説は両分布支持なら全体支持、どちらか不支持なら全体不支持、それ以外は保留。同等性の総合支持はH1/H2とも両分布支持の場合のみ。

## 4. 推定量と判定
