## 何を測るか：V・A・Q・MCSEの区別

```text
原標本i、反復r、方法mで（全分散ddof=1）：
se_i = sampleSD_ddof1/sqrt(20)
V_K  = (var_k(lower) + var_k(upper)) / (2*se_i²)
A_K  = sqrt(V_K) = S_K/se_i
S_K  = hypot(SD_L,SD_U)/sqrt(2)
Apop = S_K/(1/sqrt(20))                       母分散1は評価層のみ

delta_ir = A120_ir - A30_first_ir
d_i      = mean_r(delta_ir)
Q30_i    = var_r(A30_first_ir)
Q120_i   = var_r(A120_ir)
W_i      = Q120_i - .5*Q30_i
```

VはK本の端点から測る規格化分散指標、A=Aseはその平方根、Qは**AをJ20回測り直したときの反復分散**である。Qを端点分散V、原標本間のAの分散、原標本平均のMCSEと混同しない。CSVのAとAse、VとVseは対応する同じ有限K測定量の表記であり、平均Aの二乗が平均Vという意味ではない。原標本内でKを集計し、次にJを集計してから原標本間へ進む。

Bを増やすこととKを増やすことも異なる。今回はB4999を固定して同じ区間計算を多く繰り返し、その変動の測り方を比較した。K増加だけで1回の区間の分布が改善する、被覆が名目95%へ近づくとはいえない。

ddof1は分散の補正であり、平方根後のSDを不偏にしない。[NumPy std公式資料](https://numpy.org/doc/stable/reference/generated/numpy.std.html) 理想化して全系列で端点が定義されIID・有限二次モーメントなら、E[V_K|sample]は理想条件付き分散指標に一致し、凹性からE[A_K|sample]はその平方根以下となる。しかし本実験は理想値を計算せず、Vの性質からAの不偏性や無限Kに対する絶対偏りを推定していない。正規端点を仮定するc4補正を適用せず、補正・外挿・K120の正解性を結論しない。

**tは決定的対照でV／A／Q／JPR／deltaを厳密に0とした。** 同じtをJ/Kへbroadcastしても実質60個の原標本ごとの対照であり、各Kのプール表は各分布30区間として数える。比較区間はSE0としてNA。旧M05のK1安定性はtを含め引き続きNAで、今回のゼロ変動と置き換えていない。

## 平方根・プール・先頭組の代数的分解

```text
Vbar = mean_g(V30_g)
Abar = mean_g(sqrt(V30_g))
Jgap = sqrt(Vbar) - Abar
Pgap = sqrt(V120) - sqrt(Vbar)
Rgap = Abar - A30_first
A120 - A30_first = Jgap + Pgap + Rgap
```

Jgap≥0は平方根の凹性による**代数的性質**で、新たに実験で支持する仮説ではない。Pgapは分散プール差、Rgapは主K30として先頭組を使う差。delta全体をJensen効果と呼ばず、Jgapを理想的SDからの絶対偏りとも呼ばない。4組は分解用であり、H1／H2の先頭A30をAbarへ置き換えていない。

各端点について既知の平方和分解も全件照合した。

```text
119*s120² = 29*sum_g(s30_g²) + 30*sum_g((mean_g-mean120)²)
```

群内と群間の平方和を合わせるため、V120はV30の4組単純平均とは一般に異なる。分解は有限標本上の恒等式で、確率モデルや科学仮説の独立な検定ではない。符号・全反復・分布・残差を保存し、正の例だけを選ばない。

区間は保存IID原標本を結果によらずID選択したモデルに基づく原標本間の**近似**で、有限J／Kの測定ノイズを含む。固定60個だけを条件とする内側乱数のみの厳密区間ではない。N30で原標本別量が非正規なら近似が不十分な可能性があり、全値・分位点・seed別を残す。追加抽選・変換・外れ値除外・主検定の差替えはない。
