## 科学レビュー・問いの再設定

M06は有限K30という測定手続きにおける平均Aseの比較。H1の±.01内同等性と、H2のB増加による平均25%超低減は保持する。0を除外する小さな差と実用的同等性は両立する。低減率約54%は点推定であり、全原標本・無限B/K・被覆の保証へ拡張しない。

Bは1回のbootstrapの再標本数、Kは同じ原標本の区間計算を独立乱数で繰り返す回数。Bを増やす操作は端点の乱数変動自体を変える。Kを増やす操作は、その変動を測るAse推定の精度を変える。さらにJはK系列をまとめた測定全体の独立反復数であり、KやJを原標本数Nに足さない。

単一RQ：<b>n20・α=.05・B4999の保存原標本で、K30→120はAseの平均値を実用的にほぼ保ちつつ、Aseを繰り返し測ったときのばらつきを減らすか。観測された平均の移動を平方根の凹性と分散のプールに分けると何が残るか。</b>

候補の「有限Kの絶対偏りを測る」は狭める。K120も有限で真値ではなく、本実験が直接識別するのはK間の平均移動・反復分散差・有限標本上の代数的分解。無限Kの条件付きSDに対する絶対偏り、補正の妥当性、K120の正解性は識別しない。正規分布を前提とするc4補正も端点分布へ自動適用しない。

## 指標と平方根の分解

原標本i、反復r、方法mごと、端点の標本分散はすべてddof=1。se\_i=標本SD\_ddof1/√20を原標本から固定。

```txt
V_K = (var_k(lower) + var_k(upper)) / (2 * se_i^2)
A_K = sqrt(V_K)
主K30 = k0..29、K120 = k0..119
delta_ir = A120_ir - A30_first_ir
d_i = mean_r(delta_ir)

Q30_i  = var_r(A30_first_ir, ddof=1)
Q120_i = var_r(A120_ir, ddof=1)
W_i = Q120_i - 0.5 * Q30_i
```

QはAseを測り直したときの反復分散。端点分散V、原標本間のAse分散、平均差のMCSEと混同しない。H2の50%は分散低減でありSDの50%低減ではない。

同じr内の4組のV30\_g/A30\_gから、次を保存する：

```txt
Vbar = mean_g(V30_g)
Abar = mean_g(sqrt(V30_g))
Jgap = sqrt(Vbar) - Abar
Pgap = sqrt(V120) - sqrt(Vbar)
Rgap = Abar - A30_first
delta_ir = Jgap + Pgap + Rgap
```

Jgap≥0は平方根の凹性による代数的性質で、実験で新たに支持する仮説にしない。Pgapは分散のプール差、Rgapは主K30として先頭組を使うことによる差。Jgapを絶対偏りと呼ばず、deltaだけをJensen効果と呼ばない。Jgap、Pgap、Rgap、deltaの全符号・分布・平均と分解残差を保存し、符号が都合のよい部分だけを選ばない。

各端点について、<code>119*s120² = 29*sum_g(s30_g²) + 30*sum_g((mean_g-mean120)²)</code> も照合する。V120は4組のV30の単純平均とは違う。これは既知の平方和分解からの導出であり独立の科学仮説ではない。

理想化して全系列で端点が定義されIID・有限二次モーメントなら、E\[V\_K\|sample\]は理想条件付き分散指標に一致し、sqrtの凹性でE\[A\_K\|sample\]はその平方根以下となる。しかし本実験は理想値を計算しない。Vの不偏性からAの不偏性を主張しない。絶対偏り推定・外挿・補正は対象外。

## 事前仮説・判定

| 仮説 | 固定量・判定 |
| --- | --- |
| H1 平均の移動は実用的に小さい | 各分布mean(d\_i)の99%区間が厳密に(-.0025,+.0025)内なら支持。lo>.0025またはhi\<-.0025なら不支持。境界接触・交差は保留 |
