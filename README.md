# MATHSCAPE｜数学を触れる実験室

数式やパラメータを動かし、数学的な現象を視覚的・直感的に探索するローカルWebアプリです。
**v0.1.0** は3つのLabを搭載しています。GitHubで公開するのはソースコードであり、インターネット上でホスティングされたアプリではありません。外部Webホスティングや有料APIは利用しません。

## 3つのLab

| Lab | 操作と表示 |
| --- | --- |
| Probability Explorer | 正規・ガンマ・ベータ分布のパラメータ、PDF、平均・分散、数式、定義域と特異端点の説明 |
| Chaos Explorer | ロジスティック写像の時系列、2軌道と絶対差、分岐図、r=2.5/3.2/3.9のプリセット |
| Fractal Explorer | マンデルブロ反復の発散回数、中心・表示幅・解像度・反復数、ズーム・パン・全体表示への復帰 |

各Labはサイドバーで切り替えます。数学的な意味、探索のヒント、有限計算の限界を日本語で表示します。計算はUIから独立した `mathscape/` モジュールに分離しています。

## セットアップ

Python **3.12** を推奨します。macOS 26.6.2 / Apple Silicon arm64 / Python 3.12.13で検証しています。Python 3.11以降を想定したコードですが、依存関係の固定版を含め、3.12以外の動作は未検証です。

NumPy、SciPy、Streamlit、Plotly、pytestを使用します。`requirements.txt` は検証環境の依存関係（推移的な依存も含む）を固定しています。

```bash
git clone https://github.com/Tone75/mathscape.git
cd mathscape
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m pip check
```

依存関係の初回取得にはネットワーク接続が必要です。インストール後のアプリ操作・計算・テストに外部ネットワークは不要です。図や数式もローカル配信し、外部API・外部DBは使用しません。Streamlitの利用統計送信も無効にしています。

## 起動

プロジェクトのディレクトリで実行します。

```bash
source .venv/bin/activate
python -m streamlit run app.py
```

ブラウザで `http://127.0.0.1:8501` を開きます。サーバーはループバックアドレスのみにバインドします。停止は起動した端末で `Ctrl+C`。

既存サービスが8501を使用している場合は、別ポートを指定します。初回実装では以下のコマンドで実際に起動し、HTTP、health、ブラウザ描画を確認しています。

```bash
python -m streamlit run app.py --server.headless true --server.port 8517
```

この場合は `http://127.0.0.1:8517` を開きます。

## テスト

```bash
source .venv/bin/activate
python -m pytest -q
```

数理テストは既知のPDF・平均・分散、SciPyの適応積分による全定義域での正規化、特異端点、固定点・周期2、決定性、分岐図のパラメータ対応、既知の複素数の発散回数、独立したスカラー参照計算との一致、入力検証・計算上限を確認します。UIは `streamlit.testing.v1.AppTest` で初期表示・Lab切り替え・パラメータ変更・ボタンの状態変化を検証します。

## 数学的モデルと計算の限界

- **確率密度**：密度の高さは確率ではありません。区間の面積が確率です。ガンマ分布はshape `k`、scale `θ`、`loc=0` を明示し、rateと混同しません。正規分布は0.05%〜99.95%分位点、ガンマ分布は正の格子から99.9%分位点までを描画します。ベータ分布は0と1を除外します。ガンマの `k<1`、ベータの `α<1` / `β<1` では特異端点の密度が発散します。計算関数はその無限大を保持し、描画側で端点を省略します。表示領域の切り取りや有限格子によって、描画曲線の面積は1とは限りません。正規化テストは全定義域を適応積分します。
- **ロジスティック写像**：`x[n+1] = r*x[n]*(1-x[n])`、`0≤r≤4`、`0≤x0≤1`。同じ条件から同じ結果になる決定論的モデルです。有限時間の軌道差はカオスの厳密な証明ではありません。分岐図は400個のr（2.5〜4.0）、初期値0.2、burn-in 400回、続く80回による固定条件の近似で、時系列の操作条件とは独立しています。浮動小数点の誤差が長期軌道に影響します。
- **マンデルブロ反復**：`z0=0, z[n+1]=z[n]^2+c`。初めて `|z[n]|>2` となった反復を保存します。計算エンジンのカウント0は「最大反復まで発散未確認」を意味し、UIでは黒で表示します。有限反復で集合への所属を証明していません。実軸・虚軸は等縮尺です。Plotlyのドラッグズームは既存画像の表示操作のみで、再計算はサイドバーとボタンで行います。

## 現在の制約・拡張候補

- 初期解像度360×360、最大450×450。反復は初期80回、最大150回。表示幅は0.000001〜6、UIの中心座標は各軸−4〜4。深いズームは有限精度・有限反復の制約があります。
- 分岐図とフラクタルのキャッシュは各最大4条件、メモリ内のみです。初回計算・描画にはキャッシュが効きません。
- ユーザー保存、画像出力専用機能、任意数式入力、外部ホスティングは実装していません。Plotly標準の画像保存は利用できます。
- 将来候補：観察条件をURLやファイルで共有できる再現機能。
