# MATHSCAPE｜数学を触れる実験室

数式やパラメータを動かし、数学的な現象を視覚的・直感的に探索するローカルWebアプリです。
Inference Labを含む **RQ-M01 / v0.2** はOwner受入・ユーザー動作確認が完了し、**RQ-M02〜RQ-M05** もOwner承認済みです。RQ-M05のH1/H2実用差不支持・C/Tに限定した±1pp内同等性支持を保持し、承認と外部科学レビュー・Owner本人の個別新操作・PR mergeを区別します。今回のRQ-M06はM05の保存原標本を固定し、BCa端点の計算上の揺れを調べます。新成果は新PRでレビューに提出し、既存PR #1〜#5、main、公開済みReleaseは保持します。GitHubで公開するのはソースコードであり、インターネット上でホスティングされたアプリではありません。外部Webホスティングや有料APIは利用しません。

v0.1.1ではFractalの中心座標・表示幅とChaosのrの初期値をSession Stateへ集約し、ボタンやプリセット操作時の重複初期値警告を修正しました。ズーム・パン・直接入力・プリセット・手動操作・Lab切り替えの既存動作を維持しています。既存のv0.1.0タグとReleaseは保持しています。

## 4つのLab

| Lab | 操作と表示 |
| --- | --- |
| Probability Explorer | 正規・ガンマ・ベータ分布のパラメータ、PDF、平均・分散、数式、定義域と特異端点の説明 |
| Chaos Explorer | ロジスティック写像の時系列、2軌道と絶対差、分岐図、r=2.5/3.2/3.9のプリセット |
| Fractal Explorer | マンデルブロ反復の発散回数、中心・表示幅・解像度・反復数、ズーム・パン・全体表示への復帰 |
| Inference Lab | 母集団と1標本、未知分散の1標本両側t推論、反復信頼区間、被覆率・第一種過誤率・検出力、固定実験の標本数比較 |

Inference Lab内の「推論モード」で、従来のt推論探索、RQ-M02の「信頼区間の方法比較」、RQ-M03の「再標本化回数と端点の安定性」、RQ-M04の「分布の形と被覆」、RQ-M05の「同じ歪度、違う分布」、RQ-M06の「同じ標本でも端点は揺れる」を切り替えます。第五のLabは作りません。

各Labはサイドバーで切り替えます。数学的な意味、探索のヒント、有限計算の限界を日本語で表示します。計算はUIから独立した `mathscape/` モジュールに分離しています。

Python **3.12** を推奨します。macOS 26.6.2 / Apple Silicon arm64 / Python 3.12.13で検証しています。Python 3.11以降を想定したコードですが、依存関係の固定版を含め、3.12以外の動作は未検証です。

## Inference LabとRQ-M01

問いは「同じ真の平均差でも、標本数と母分布の形で、t推論の区間幅・被覆率・第一種過誤率・検出力はどう変わるか」です。正規と中心化指数を、真の平均 `μ0+σd`、分散 `σ²` が同じになるよう生成します。中心化指数は `μ0+σ(d+E−1), E~Exp(1)` であり、通常のガンマ分布とは呼びません。

画面は正規／n=20／d=0／α=0.05／seed=0／B=500から開始します。nは1標本中の観測数、Bは独立実験の反復数です。μ0=0、σ=1の標準化単位で比較します。n≤200、B≤5,000、n×B≤1,000,000。条件は実行ボタンで適用し、結果には適用済み条件を表示します。αだけを変えて再実行しても同じ標本を使い、Lab往復でも直前の適用済み結果を保持します。「新しい標本」は試行IDを明示して変更します。

推論関数に渡すのは標本・帰無平均・αのみです。標本分散はddof=1、自由度n−1、SE=s/√n、T=(標本平均−μ0)/SE、p=2t.sf(|T|)、棄却は丸め前のp<αです。区間は標本平均±t臨界値×SE。被覆率は真の平均を含む割合で、帰無平均を含む割合ではありません。ゼロ分散などの無効結果は明示し、黙って分母から除外しません。

反復区間は先頭最大100本だけを描画し、集計は全B回から求めます。率には95% Wilson区間とMonte Carlo標準誤差、平均区間幅にもMonte Carlo標準誤差を表示します。d=0の棄却率は第一種過誤率、d≠0なら検出力と呼びます。非心tによる理論検出力は正規条件にだけ表示します。

信頼水準は手続きの反復被覆率です。実現済みの区間に真値が95%の確率であるとは解釈しません。p値は帰無仮説が正しい確率ではなく、不棄却は効果なしの証明ではありません。統計的有意性と効果の大きさ・実用上の重要性は区別します。正規IID以外ではt推論の名目水準は厳密には保証されず、今回の有限MC結果は一般的な証明ではありません。

固定54ケースの設計・全結果・科学レポートは [evidence/rq_m01](evidence/rq_m01/) に保存します。固定比較のαは0.05、dは0／0.2／0.5、master seedは0／1／2です。自由探索と条件が一致しない場合は固定結果と混ぜません。実行手順・試行制限は [REPORT.md](evidence/rq_m01/REPORT.md)、次の作業者への最小情報は [HANDOFF.md](HANDOFF.md) を参照してください。通常pytestは固定実験全体を再実行しません。

### RQ-M05：同じ歪度、違う分布

母平均0・母分散1・母歪度2を解析的に揃えたガンマ `Gamma(1,1)−1` と対数正規を比較します。対数正規の定数は丸めず `v=2sinh(asinh(1)/3)`、`t=1+v²`、`s=√log1p(v²)`、`m=√t`、`d=√t v` として `X=(exp(sZ)−m)/d` を生成します。理論値をSciPyのmvskと照合し、原標本の実現モーメントを強制調整しません。推論対象はXの算術平均です。異なる尖度・支持域・尾の形が残るため、尖度単独の因果効果とは呼びません。

2分布×3seed×R10000、n20／名目95%／K1／B4999。各分布30,000、計60,000の独立原標本と1本ずつのbootstrap系列を使います。同一原標本のpercentile／BCaだけ平均列を共有し、異なる分布は同じseed／outer IDでも独立群です。K1では端点SD／S／Ase／Apopは推定不能としてNAにします。旧安定性ビューを保持します。

確認的対象はBCaの被覆差ΔCと非被覆方向差ΔT（ともに対数正規−ガンマ）のみ。独立Welch99%区間が±1pp帯の外なら実用差支持、厳密に内側ならこの固定条件・該当指標での実用的同等性支持（実用差仮説は不支持）、境界接触やまたぎは保留です。必要データの欠損／無効、SE0／非有限もNA・保留。非有意だけで同等とせず、seed同符号の追加ゲートは置きません。t／percentileの分布差・方法内対応差は記述結果です。

固定仕様は [SPEC.md](evidence/rq_m05/SPEC.md)。生成・数理・集計／判定・独立監査・guard・乱数写像・環境・保存schemaと容量を事前commitで固定します。主実験1回、外側300秒／2GiB／追加50MiB／再標本バッチ100万要素以内。通常pytest・保存監査・UIは主実験を起動せず、旧RQ-M01〜M04を再実行・上書きしません。新成果はレビュー待ちとして提出します。

### RQ-M04：分布の形と被覆

`G~Gamma(shape=r, scale=1), X=(G−r)/√r` とし、r=.5／1／2／4／16と正規対照N(0,1)を比較します。母平均0・母分散1・n=20・両側α=.05を固定し、原標本自体を平均0・分散1へ再標準化しません。形状rを変えると理論歪度2/√r、超過尖度6/r、下限−√rが同時に変わるため、歪度単独の因果効果とは扱いません。r=16は正規分布とは別の条件です。

各分布×seed=0／1／2でR=400独立原標本、各原標本にK=10独立再標本化系列。B=999／4,999は同じ平均列のprefixです。18生成セル、7,200原標本、72,000内側系列、各分布のプール独立単位は1,200原標本です。異なる形状は独立群で、同じseed／outer IDでも対応標本とは数えません。同じ原標本のB比較と手法比較は対応差を用います。KやBを独立な母集団標本数へ加算しません。

被覆C、区間全体が真値より下へ外す率Mbelow=I(U<0)、上へ外す率Mabove=I(L>0)、方向差T=Mbelow−Maboveを別表示します。端点の揺れSは上下端点分散（ddof=1）の平均の平方根。標本SE尺度Ase=S/(s/√20)、既知の母SE尺度Apop=S/(1/√20)、生の端点SDを併記します。Apopはシミュレーション評価専用であり、母分散や形状を推論APIへ渡しません。有限K=10のAを旧RQ-M03のK=20と同じ条件の数値として比較しません。

確認的対象はBCa／B=4,999の2量だけです。H1はr=.5−r=16の被覆差（独立2群Welch 99%区間上限<−.02、全seed差<0）、H2はr=.5のT（原標本単位t 99%区間下限>.03、全seed平均T>0）。中間形状、B差、手法間差は記述分析です。無効が必要な原標本にあれば主比較はNA／保留とし、別分布やB999だけの無効で完全な確認的対象まで自動で無効化しません。無効を非被覆とは数えません。

新ビューは [evidence/rq_m04](evidence/rq_m04/) の保存結果だけを読みます。B／k／手法／Lab往復で原標本を保持し、分布を変えると別原標本であることを表示します。元の分布に戻ると保存IDを復元します。母分布PDFの表示窓と端点省略を説明し、r<1での端点密度の発散を巨大な有限値へ置換しません。標本から作る95%区間と、被覆推定の99% Monte Carlo区間、固定αと旧自由αを区別します。

### RQ-M02：信頼区間の方法比較

同じ原標本にt・percentile bootstrap・BCaの3手法を適用します。percentileとBCaは同じ999個のbootstrap平均を使います。推論APIへ真の母平均・母分散・分布名は渡しません。tはddof=1／df=n−1、分位点はNumPy linear、BCaの同値は半分としてz₀を計算し、delete-one jackknifeに対応する加速係数aで分位点を補正します。都合のよいクリップや、計算不能時の別手法への置換はしません。

自由操作は正規／中心化指数、n=5・20・100、α=0.01・0.05・0.10、seedと試行IDです。真の平均0・分散1・d=0、B_boot=999固定。既定は中心化指数・n=5です。αだけの適用変更、表示する手法、Lab／モード往復では原標本とbootstrap平均を保持します。未適用入力と結果条件を分け、原標本の再生成は明示操作で行います。bootstrap区間にt由来のp値や検出力は付けません。

画面の反復比較は `evidence/rq_m02/` に保存した固定結果だけを読みます。先頭最大50原標本の3区間を描き、集計は全外側R=2,000回を使います。自由操作のαと固定比較α=0.05、原観測数nと内側再標本化回数B_boot、外側Rを区別します。短い区間だけでは性能を順位づけできず、被覆率・幅・真値を外す側・無効数を一緒に確認します。再標本化しても元の観測情報は増えません。

固定設計は2母分布×n=5/20/100×seed=0/1/2、各R=2,000・B_boot=999の18生成セル／54手法別行です。外側標本ごとに原標本と再標本の別系列を作り、全外側反復に共通のインデックス配列を使いません。manifestと数理ソースを実験前commitで固定します。旧RQ-M01は再実行・上書きしません。新しい[科学レポート](evidence/rq_m02/REPORT.md)に仮説判定・全結果・資源・再現コマンドをまとめます。通常pytestは主実験を起動しません。

非有限・定数標本・BCa計算不能は理由付き無効です。無効を被覆失敗と数えたり、黙って分母から除いたりしません。調整分位点の尾部で実効bootstrap回数が10未満なら警告しますが、反復追加や定義変更はしません。本実験は有限B_bootの手続きの性能であり、bootstrap一般の優越やn=100一般への保証を示すものではありません。

- **確率密度**：密度の高さは確率ではありません。区間の面積が確率です。ガンマ分布はshape `k`、scale `θ`、`loc=0` を明示し、rateと混同しません。正規分布は0.05%〜99.95%分位点、ガンマ分布は正の格子から99.9%分位点までを描画します。ベータ分布は0と1を除外します。ガンマの `k<1`、ベータの `α<1` / `β<1` では特異端点の密度が発散します。計算関数はその無限大を保持し、描画側で端点を省略します。表示領域の切り取りや有限格子によって、描画曲線の面積は1とは限りません。正規化テストは全定義域を適応積分します。
- **ロジスティック写像**：`x[n+1] = r*x[n]*(1-x[n])`、`0≤r≤4`、`0≤x0≤1`。同じ条件から同じ結果になる決定論的モデルです。有限時間の軌道差はカオスの厳密な証明ではありません。分岐図は400個のr（2.5〜4.0）、初期値0.2、burn-in 400回、続く80回による固定条件の近似で、時系列の操作条件とは独立しています。浮動小数点の誤差が長期軌道に影響します。
- **マンデルブロ反復**：`z0=0, z[n+1]=z[n]^2+c`。初めて `|z[n]|>2` となった反復を保存します。計算エンジンのカウント0は「最大反復まで発散未確認」を意味し、UIでは黒で表示します。有限反復で集合への所属を証明していません。実軸・虚軸は等縮尺です。Plotlyのドラッグズームは既存画像の表示操作のみで、再計算はサイドバーとボタンで行います。
